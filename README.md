# Chickfilmenu — Chick-fil-A Menu with Prices & Calories

The landing page for [chickfilmenu.us](https://chickfilmenu.us/) — every Chick-fil-A sandwich, side, treat and drink with prices and calories, updated for 2026.

- **Live site:** https://chickfilmenu.us/
- **This page:** https://saleemsial1.github.io/chickfilmenu/

## What's here

- `index.html` — the landing page (single file, no build step)
- `images/` — official Chick-fil-A product photos (transparent WebP)

## Facts on the page

Calories are from the official Chick-fil-A nutrition guide. Chick-fil-A publishes no national prices, so prices are shown as varying by location. The site is an independent informational website and is not affiliated with or endorsed by Chick-fil-A.
